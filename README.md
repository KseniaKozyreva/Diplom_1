## Модульное тестирование бизнес-логики Stellar Burgers 🚀

### Автотесты для проверки программы, которая помогает заказать бургер в Stellar Burgers

### Реализованные сценарии

Созданы юнит-тесты, покрывающие классы `Bun`, `Burger`, `Ingredient`, `Database`

Процент покрытия 100% (отчет: `htmlcov/index.html`)

### Структура проекта

- `praktikum` - пакет, содержащий код программы
- `tests` - пакет, содержащий тесты, разделенные по классам. Например, `bun_test.py`, `burger_test.py` и т.д.

### Запуск автотестов

**Установка зависимостей**

> `$ pip install -r requirements.txt`

**Запуск автотестов и создание HTML-отчета о покрытии**

>  `$ pytest --cov=praktikum --cov-report=html`

### 📊 Итоги работы

* Бизнес-логика приложения полностью покрыта изолированными модульными тестами (Unit-тестами).
* В ходе тестирования успешно применены техники тест-дизайна (эквивалентное разделение, граничные значения) и мокирование объектов (`unittest.mock`).
* Процент покрытия кода тестами составляет **100%**, что подтверждено сгенерированным HTML-отчётом (`pytest-cov`).
